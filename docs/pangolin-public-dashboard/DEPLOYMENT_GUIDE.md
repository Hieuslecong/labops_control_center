# Deployment guide

1. Confirm an approved VPS, public IP, DNS ownership, and admin access. Use the [official pinned installation](https://docs.pangolin.net/self-host/quick-install) for Pangolin, Gerbil and Traefik. Review the release installer and generated Compose before running it. Preserve the persistent configuration and certificate directories, pin generated image versions, configure log rotation, and back up state before upgrades.
2. Verify VPS TCP 80/443 and UDP 51820 against the [official networking guide](https://docs.pangolin.net/self-host/dns-and-networking). Add UDP 21820 only when the chosen setup uses client tunneling. Obtain approval for DNS and firewall changes. Point both management and Dashboard records to the VPS.
3. Create the aiot-ws1 site and obtain its Newt credentials through the Pangolin admin UI. Select a compatible stable version from [Newt releases](https://github.com/fosrl/newt/releases). Run the connector installer with the reviewed binary and checksum. Use sudoedit to create /etc/labops-pangolin/newt.env using the environment template, and set ownership root:root and permissions 0600.
4. With approval to start the connector, run sudo systemctl daemon-reload and sudo systemctl enable --now labops-newt.service. Verify site online in Pangolin and confirm the local Next.js target responds.
5. Create one Public HTTP/HTTPS resource for LabOps Control Center, targeting 127.0.0.1:3000 via aiot-ws1. Require Pangolin authentication and restrict it to LabOps-Admins. Confirm HTTPS and the browser access matrix before approving go-live.

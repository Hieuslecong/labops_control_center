# Metric dictionary (normative V1)

Authoritative measurement, not presentation, determines meaning. New normalized DTO fields are explicit; preserve legacy fields and units unchanged. The source ledger in 01 identifies inspected code; field availability in production is unverified. Each metric carries quality and observation timestamp (directly or via its snapshot), scope and source. Unknown, unsupported, permission error, stale, missing and valid zero are distinct. Do not synthesize observations.

| Metric | Type / unit | Scope and computation | Invalid/unknown rules |
|---|---|---|---|
| `observed_workloads` | nullable integer count | distinct root identities with fresh observation, in authorized selected entity scope; monitoring included but classified separately; excludes protected/system in workload mode | all unavailable => null; partial => observed count only + PARTIAL; fresh complete empty => 0 |
| `last_known_workloads` | nullable integer count | deduplicated stale rows separately (not added to observed count) | no reliable stale cache => null |
| `gpu_associated_workloads` | nullable integer | fresh roots with gpu_associated true, including monitoring if actually GPU-associated; report unknown count | do not substitute VRAM=0 for missing association |
| `gpu_association_unknown` | nullable integer | fresh roots with gpu_associated null | unknown count is not non-GPU count |
| `observed_members` | nullable integer | distinct immutable verified member IDs of fresh roots; unknown ownership separately | username only is not verified member ID; disclose unmapped count |
| `device_vram_used_bytes`, `device_vram_capacity_bytes` | nullable nonnegative integer bytes | sum only paired fresh authoritative device memory observations in selected node/GPU scope, ignore member/group/search; show observed capacity/expected devices | offline excluded, not zero; no denominator if unknown; used>capacity => inconsistency, no percent/free |
| `gpu_coverage` | fresh/expected integer pair (expected nullable) | count distinct fresh GPU UUIDs against authoritative authorized inventory in node/GPU scope | expected unknown => unknown ratio; expected=0 => N/A not 100%; don't derive inventory from online rows |
| `attention_count` | nullable integer | distinct validated workload-related conditions within scope | N/A without trustworthy rule coverage; never use generic system incident count as workload count |
| `cpu.value_percent` | nullable number | instantaneous or interval average according to source; basis `PER_CORE_PERCENT`, `HOST_CAPACITY_PERCENT`, `UNKNOWN`; per-core may exceed 100 | do not normalize by guessed core count; no percentage gauge when denominator unknown |

| `elapsed_seconds` | nullable nonnegative integer seconds | observed runtime from verified source, not display string; actual start optional UTC | unknown sorts last in both directions; tie-break stable ID; no lexical sorting |
| `gpu_utilization_percent` | nullable number 0–100 | device GPU utilization over actual sampling window (not VRAM usage) | no gaps filled with 0; no attribution to user without source |
| `temperature_celsius` | nullable number | device sensor, source/cadence and threshold metadata if verified | don't infer sensor value or universal thermal threshold |

## Scope and identity rules
- Node/GPU filters select inventory/device scope; member/group select workload scope only; search/sort/pagination apply table only. Live KPI and history range independent. Group relation must be verified, use stable member/group ID; historical group is recorded group at observation if available, otherwise explicitly label current-group attribution and don't silently combine. Unknown group separate, not inferred from username. Reject or explicitly clear impossible filter combinations; unauthorized filters return 403 or consistent non-disclosing not-found policy.
- `workload_kind` independent from GPU association: TRAINING, INFERENCE, NOTEBOOK, GENERAL_COMPUTE, MONITORING, SYSTEM, OTHER, UNKNOWN. Training/inference only with positive evidence; Python alone is not proof. Preserve legacy classification. `kind_confidence`: VERIFIED/HEURISTIC/UNKNOWN with evidence; never trust user text as authoritative. `gpu_associated`: true/false/null. Composition precedence: monitoring first; remaining GPU true; remaining confirmed non-GPU compute (training/inference/notebook/general); remaining other/unknown. Sum exactly equals fresh root count.
- New stable identity includes node, boot ID, host PID, kernel start ticks, container identity and UID where available. For host process, explicit host/no container; missing container metadata not trusted. Server generated opaque ID; legacy incomplete identity may support read-only display, never action. Action token/ref bound to exact current identity; no use of historical identifier to signal.
- Convert source MiB to bytes using 2^20 only after auditing actual field units. GiB = bytes/2^30. Device totals and process totals must not be forcibly reconciled: different timestamps/rounding/unattributed usage; negative free never shown. Format UI rounding after aggregation; preserve precision in API. Use ISO UTC internally and Asia/Ho_Chi_Minh in UI; timestamp from source, not request completion. Duplicates resolved by documented sequence/quality policy; conflicting same timestamp flagged rather than double counted.
- Quality enum: FRESH, STALE, OFFLINE, NOT_CONFIGURED, UNSUPPORTED, NO_DATA, ERROR, UNKNOWN, PARTIAL (aggregate). Proposed default stale threshold three expected sample intervals (verify per source). Historical gap threshold two expected intervals; no bridging. Null means unavailable, not zero. Valid zero only with positive successful observation. Stale values may be shown explicitly separately, never counted as fresh. Source failure never advances last-success timestamp.
- Stable owner/device color is deterministic by immutable ID; legend independent of order and filters. Unknown uses gray. For multiple series capped by top-N, aggregate other only for additive comparable metrics; never average arbitrary utilization across devices without weights/label.
